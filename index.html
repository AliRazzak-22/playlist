حماية قاعدة البيانات

هاي القواعد تعطي لهذا المتصفح وحده صلاحية تغيير الفيديوهات والأوامر والإعدادات. ما تحتاج حساب بريد؛ Firebase ينشئ تعريف تلقائي للمتصفح. قراءة روابط الفيديوهات والتحديثات تبقى عامة حتى الشاشات تكدر توصل إلها.

رمز الدخول قفل محلي للواجهة وموجود في ملفاتها، مو كلمة سر للخادم. لا تمسح بيانات المتصفح أو تبدّل المتصفح؛ إذا صار تعريف جديد، تحتاج تنشر قواعده مرة ثانية. نشر قواعد متصفح جديد بدل القديمة يلغي صلاحية المتصفح السابق.

تقارير حالة الشاشات تُرسل بدون تسجيل دخول للجهاز، لذلك ممكن طرف آخر يزوّر حالة شاشة إذا عرف رمزها الكامل. لا تعتبر علامة «متصلة» إثبات هوية؛ توثيق الأجهزة يحتاج ربط آمن إضافي.

  1. اضغط زر نسخ القواعد اللي جوة.
  2. افتح صفحة القواعد بـ Firebase.
  3. امسح كل النص الموجود هناك، والصق القواعد مكانه.
  4. اضغط Publish، وبعدها ارجع هنا واضغط فحص مرة ثانية.
